# Publish with scripts\publish-denylist.ps1 from the Aether checkout. Every client picks the file
# up on its next start. A name removed from here stops being refused the same way: the client
# writes nothing to the machine for these, so this file is the whole of the refusal.

# the signature of, which means the service can be moved -- to a domain of its own, or to another
# host entirely -- without a release, and without stranding a client that missed one. Only this
# file's signature decides it, so nobody else can point a client at their own server. Anything
# that is not plainly an https address is ignored, and the client falls back to the address it
